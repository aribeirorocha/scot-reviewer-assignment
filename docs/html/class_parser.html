◆ parseFile()

bool Parser::parseFile ( const std::string & filename)

Lê e processa o conteúdo de um ficheiro CSV.

Motor principal de parsing que lê o ficheiro CSV e popula as listas de dados.

Parameters
filenameCaminho para o ficheiro a ser lido.
Returns
true se o processamento foi concluído sem erros fatais, false caso contrário.

Complexidade Temporal: O(L * C), onde L é o número de linhas e C o número médio de caracteres.

  • O método utiliza uma máquina de estados simples baseada na variável currentSection para distinguir entre blocos de Submissões, Revisores e Parâmetros.
  • Parameters
    filenameCaminho para o ficheiro CSV.
    Returns
    true Se o ficheiro foi processado com sucesso, false caso contrário.

Complexidade Temporal: O(L * C), onde:

  • L é o número total de linhas no ficheiro.
  • C é o número médio de caracteres/colunas por linha. Cada linha é lida uma única vez e processada sequencialmente.
