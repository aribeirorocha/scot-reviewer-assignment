◆ loadData()

bool App::loadData ( const std::string & filename)

Carrega os dados de um ficheiro CSV e desencadeia a construção do grafo.

Carrega os dados do ficheiro fornecido e inicializa a estrutura do grafo.

  • Parameters
    filenameCaminho relativo ou absoluto para o ficheiro .csv de entrada.
    Returns
    true se o ficheiro foi lido e os dados carregados com sucesso, false caso contrário.

Complexidade Temporal: O(N * M + S + R), onde N é o número de linhas, M o comprimento das linhas, S o número de submissões e R o de revisores.

  • Parameters
    filenameCaminho para o ficheiro CSV de entrada.
    Returns
    true Se o ficheiro foi lido e o grafo construído com sucesso.
    false Se ocorreu um erro na leitura do ficheiro.

Complexidade Temporal: O(N * M + S + R), onde:

  • N é o número de linhas no ficheiro.
  • M é o comprimento médio de cada linha.
  • S é o número de submissões.
  • R é o número de revisores.
